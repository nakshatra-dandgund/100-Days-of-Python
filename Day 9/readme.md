## 🧠 Project Overview
**Project Name:** ATM Machine Simulator
**Author:** Nakshatra Dandgund

This program simulates a real-life **ATM machine system** where users can:
- Enter a PIN
- Check balance
- Deposit money
- Withdraw money
- Exit safely

---

## ⚙️ Features
- 🔐 Secure PIN system (3 attempts limit)
- 💰 Balance checking
- ➕ Deposit functionality
- ➖ Withdrawal with balance validation
- 🔁 Menu-driven interface using loops
- ❌ Handles invalid inputs

---

## 📄 How It Works
1. User enters PIN (maximum 3 attempts)
2. If correct → access ATM menu
3. Choose an operation:
   - Check balance
   - Deposit money
   - Withdraw money
   - Exit
4. Program continues until user exits
